Write the commands to run, the text to type, and the output to wait for in a
<a href="./authoring/tape-files/">tape file</a>. Betamax runs the session and saves the recording.
It uses <a href="./reference/vhs-differences/">libghostty-vt</a> to parse terminal output and renders
frames in Rust.
