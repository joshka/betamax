Betamax uses Ghostty-style theme files to map terminal color indexes and named colors into rendered
RGB values. It searches user Ghostty theme directories first, then the copied themes bundled with
`betamax-core`. See [Differences from VHS](../../reference/vhs-differences/) for compatibility
details and unsupported features.

```sh
betamax themes
betamax themes --json
betamax themes --markdown
```

Use the exact listed name in a tape:

```tape
Set Theme "Aardvark Blue"
```

## Theme lookup

Bundled themes make tapes portable across machines. User Ghostty themes make local experimentation
convenient. Because user themes are searched first, a local theme with the same name as a bundled
theme can change a recording on that machine. For reproducible project assets, prefer a bundled
theme name and run examples in CI or a consistent environment.

The default theme is `Aardvark Blue`. It was chosen as a readable, VHS-like default for examples,
not because it has special behavior in the renderer.

## Layout settings

These settings affect the final output frame and PTY grid:

| Setting         | Default          | Purpose                                     |
| --------------- | ---------------- | ------------------------------------------- |
| `Width`         | `1200`           | Final output width in pixels                |
| `Height`        | `600`            | Final output height in pixels               |
| `Padding`       | `60`             | Space between cells and terminal edge       |
| `FontFamily`    | `JetBrains Mono` | Preferred font family                       |
| `FontSize`      | `22`             | Font size in pixels                         |
| `LetterSpacing` | `1`              | Extra pixels between terminal cells         |
| `LineHeight`    | `1`              | Multiplier applied to font size             |

Betamax derives PTY columns and rows from these values. Increasing padding or font size usually
reduces the terminal grid size; increasing width or height usually increases it.

When testing application layout, start with the default `FontSize` and `Margin`. Increase the canvas
size if needed. See [Presentation and layout proof](../tape-files/#presentation-and-layout-proof).

## Frame decoration

These settings are applied after the raw terminal frame is rendered:

| Setting          | Default          | Purpose                      |
| ---------------- | ---------------- | ---------------------------- |
| `Margin`         | `0`              | Outer frame margin in pixels |
| `MarginFill`     | theme background | Solid or linear backdrop     |
| `WindowBar`      | empty / disabled | Synthetic window bar mode    |
| `WindowBarSize`  | `30`             | Window bar height in pixels  |
| `WindowBarColor` | theme background | Window bar fill color        |
| `BorderRadius`   | `0`              | Rounded-corner mask radius   |
| `Shadow`         | `false`          | Enable a black window shadow |
| `ShadowBlur`     | `28`             | CSS blur radius in pixels    |
| `ShadowOffset`   | `9`              | Vertical offset in pixels    |
| `ShadowOpacity`  | `0.55`           | Shadow opacity, clamped 0..1 |

`WindowBar` currently treats any non-empty value as enabled. Modes ending in `Right`, such as
`RingsRight` and `ColorfulRight`, place the window buttons on the right. Other non-empty values
place them on the left.

```tape
Set Margin 12
Set MarginFill "#111111"
Set WindowBar Colorful
Set WindowBarSize 34
Set WindowBarColor "#0f101a"
Set BorderRadius 8
```

`MarginFill` also supports Betamax's owned `linear(...)` syntax:

```tape
Set MarginFill "linear(#232640, #0f101a)"
Set MarginFill "linear(to: bottom-right, #232640, #0f101a)"
Set MarginFill "linear(angle: 135deg, #4d5b9e 0%, #232640 42%, #0f101a 100%)"
```

Without a direction, the gradient runs from top to bottom. `to:` points from the first stop toward
the last and accepts `top`, `top-right`, `right`, `bottom-right`, `bottom`, `bottom-left`, `left`,
or `top-left`. `angle: <number>deg` points from the first stop toward the last, clockwise from
upward. Use comma-separated stops, with an optional percentage on every stop. This is not a CSS
parser; radial gradients and image fills are not supported yet.

The gradient covers the full output, including rounded corners and the caption row, with rounded
sRGB channel interpolation and fixed ordered dithering to soften GIF banding. A single `#rrggbb`
color keeps a solid fill. Without `MarginFill`, the backdrop follows the final theme background;
an empty string disables the margin. Invalid colors or gradients fall back to the active theme
background. Fill strings are not checked by the syntax-only `betamax validate` command. Setting a
theme before or after an explicit fill preserves that fill. See
[Margin fill](../../reference/tape-reference/#margin-fill) for the full syntax.

`Shadow` is rendered over the full `MarginFill` backdrop after it has resolved its color or
gradient. `ShadowBlur` follows CSS: sigma is half the blur radius, so the default `28` gives sigma
`14`. For an unclipped result, use at least `ShadowBlur + abs(ShadowOffset)` pixels of margin
(about `37` with the defaults); `Margin 44` leaves room for the tail. A gradient or backdrop
lighter than near-black makes the shadow easier to see.

```tape
Set Margin 44
Set MarginFill "linear(to: bottom-right, #4d5b9e 0%, #232640 42%, #0f101a 100%)"
Set Shadow true
Set ShadowBlur 28
Set ShadowOffset 9
Set ShadowOpacity 0.55
```

`WindowBarColor` accepts a `#rrggbb` string and defaults to the theme background. An explicit
color takes precedence even if `Set Theme` comes later. Invalid colors, including an empty string,
fall back to the active theme background. The setting is ignored when the bar is disabled. It changes
only the bar fill; `BorderRadius` rounds the window's outer corners.

## Timing and cursor styling

`Framerate` controls capture cadence. `PlaybackSpeed` changes output playback speed without
speeding up shell execution. `LoopOffset` rotates animated frames so a GIF loop can begin at a less
jarring point.

`CursorBlink` defaults to `true`. Set it to `false` for deterministic demos where a blinking cursor
would create unnecessary frame differences.

```tape
Set Framerate 50
Set PlaybackSpeed 1.0
Set LoopOffset 10%
Set CursorBlink false
```

## Current theme boundary

Betamax applies the selected theme in its Rust renderer. The
[`libghostty-vt`](../../reference/vhs-differences/) terminal parser is not initialized with the
selected palette. Betamax uses the loaded theme when rendering media and serializing state styles.
