# betamax-fonts

Font data that [Betamax](https://github.com/joshka/betamax) embeds so its default `FontFamily`
renders the same on every machine.

This crate contains the unmodified JetBrains Mono 2.304 variable fonts, upright and italic, from
<https://github.com/JetBrains/JetBrainsMono/releases/tag/v2.304>.
